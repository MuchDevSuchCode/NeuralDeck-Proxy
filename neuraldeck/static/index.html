Proxy Auth Tokens 

    

      Bearer tokens for the proxy on port . The proxy is open until the
      first token exists; after that every request must send one as Authorization: Bearer …
      (or x-api-key). A token is shown once, when made; only its hash is kept. The Chat tab and Prompt Lab
      keep working without one. Changes apply at once, no restart.
    

    

      
New token  — copy it now; it will not be shown again.

        · curl: -H "Authorization: Bearer <token>"
